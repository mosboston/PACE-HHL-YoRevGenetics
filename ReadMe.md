# Set up

There a few things to do after cloning the repos and opening the project.

1. Inside the Unity project directory, open the folder called `Build` (there should be an `Assets` folder and `config.xml` in there)
2. Inside the `Build` folder, make `Application` and `Logs` folders (you can leave them empty)
3. Inside `Build\Assets\Genetics` if there is no `Shared` or `EN` folder, create them (new folders can stay empty)

Try to run it in editor. If it fails, try one more time. If it is still failing, it is troubleshooting time! The errors provided tend to be quite helpful.
